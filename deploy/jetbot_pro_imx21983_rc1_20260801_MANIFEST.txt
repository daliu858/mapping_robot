Purpose
-------
This archive is an overlay for the existing jetbot_pro source tree. It contains
only the reviewed files changed or added for stereo capture, semantic mapping,
teleoperation safety, build/install hygiene, and regression tests. It excludes
the unchanged legacy voice files that contain historical embedded credentials.

Safe first run
--------------
roslaunch jetbot_pro stereo_camera.launch \
  start_stereo_image_proc:=false start_pair_gate:=false

Do not enable stereo_image_proc or semantic mapping until the camera is rigidly
mounted and real left/right calibration YAML files have been generated.
