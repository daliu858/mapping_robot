Date: 2026-08-01
Expected base repository commit: b76d483
Supersedes: RC1 overlay

Purpose
-------
This archive is a complete overlay for the existing jetbot_pro source tree. It
contains the RC1 stereo/semantic-map/teleoperation changes plus the RC2 camera
rate correction derived from real Jetson Nano + IMX219-83 measurements. It
excludes unchanged legacy voice files that contain historical embedded
credentials.

RC2 change
----------
- Direct stereo capture defaults to 640x480 at 30 FPS.
- camera_select.launch chooses stereo=30 FPS and legacy mono=20 FPS.
- The strict timestamp gate remains 20 ms; it was not weakened to hide bad
  pairing.
- Static tests lock these launch defaults.

Safe first run
--------------
roslaunch jetbot_pro stereo_camera.launch \
  start_stereo_image_proc:=false start_pair_gate:=false

Do not enable stereo_image_proc or semantic mapping until the camera is rigidly
mounted and real left/right calibration YAML files have been generated.
