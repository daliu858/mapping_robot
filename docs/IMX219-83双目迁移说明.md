# IMX219-83 双目迁移说明

## 当前硬件结论

- 左相机：`sensor-id=1`
- 右相机：`sensor-id=0`
- 正式采集：`640x480 @ 30 FPS`
- 标定基线约 `60.06 mm`
- 五图恢复标定结果：RMS 约 `0.277 px`，p95 约 `0.513 px`
- 正式深度来自双目视差，不再采用“单目目标框 + 低位 2D LiDAR 借深度”
- 双目 PCB 必须刚性固定；每次正式采集必须显式记录 `camera_mount`

## 一趟式数据流

```text
gmapping + IMX219-83 左右压缩图 + LiDAR + odom + TF
  -> 保存最终 occupancy map 并封入地图身份
  -> PC 使用 LLMDet-Large 检测 POI
  -> 离线 stereo_image_proc 计算视差
  -> bbox 中央区域多像素稳健深度
  -> camera_mount + 录制的 SLAM TF 投到 map
  -> semantic_objects.yaml
  -> 房间分割、拓扑表与三层合并
  -> occupancy grid + POI 标签可视化图
```

这里不需要 AMCL。图像时刻的坐标来自录制的：

```text
map -> odom -> base_footprint -> stereo_left_optical
```

## 正式失败条件

出现以下任一情况时不提交正式 bag 或语义地图：

- 左右相机、CameraInfo、LiDAR、odom 或 SLAM TF 中断；
- 相机外参与录制事务不一致；
- 最终地图保存或哈希校验失败；
- bag 没有唯一的 STARTED → COMPLETED 事务；
- 双目没有有效深度；
- `chair/table/door` demo 标签不完整；
- 任一后处理产物与源 bag 或地图身份不一致。

本项目不再提供语义目标自动导航功能；最终产物是供学生查看的带标签室内地图。
