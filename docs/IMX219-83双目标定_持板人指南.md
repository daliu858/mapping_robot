# IMX219-83 双目标定：持板人操作指南

这份指南写给拿棋盘格的人。您不需要懂机器人，也不需要操作电脑、鼠标或键盘；只要听电脑旁操作者的口令，慢慢移动棋盘并停稳即可。

预计耗时：约 5～10 分钟。

## 最重要的四句话

1. 整张棋盘必须始终朝向两个镜头，并且不能被手遮住。
2. 每移动到一个姿势后，保持完全不动 2～3 秒。
3. 听到操作者说“收到”或“下一个”之后，再继续移动。
4. 全程不要碰机器人、摄像头、支架或橙色排线。

## 开始前：由家人完成

### 1. 检查打印尺寸

打印时应选择：

- A4 纸；
- “实际大小”或“100%”；
- 单面打印；
- 不要选择“适合页面”“缩放到纸张”或“小册子”。

打印后必须用直尺量纸上的 **100 mm 检查线**：

- 测得 99～101 mm：可以使用；
- 相差超过 1 mm：不要使用，重新按“实际大小”打印。

棋盘应有 9×7 个黑白方格，即 8×6 个内部交点；每个方格边长约 24 mm。

### 2. 把纸贴到硬板上

打印纸不能软塌、卷曲或起皱。请把它固定到平整的硬物上，例如硬纸板、泡沫板、文件夹硬封面或比 A4 稍大的硬皮书封面。

1. 将纸平铺在硬板上，棋盘朝外。
2. 只用胶带固定四周空白处，不能盖住黑白方格。
3. 从侧面看一眼，确认纸张没有鼓包、褶皱或弯曲。
4. 不要覆盖透明塑料膜；亮面反光会妨碍识别。

### 3. 检查相机已经固定

两个镜头所在的双目相机 PCB 必须已经牢固安装在最终支架上。不能让相机靠橙色排线吊着，也不能在标定时用手托住相机。相机在标定后只要移动过一点，原标定就可能失效。

如果相机板仍会晃动，请先停止，不要开始标定，并告诉电脑旁操作者。

## 布置环境

- 打开稳定的室内照明，让黑格和白格清晰可见。
- 避免窗户或强灯正对棋盘；棋盘表面不要出现大片反光。
- 手臂和身体不要在棋盘上投下大片阴影。
- 机器人放在稳定、平整的位置，标定期间不能移动。
- 雷达不需要开启。
- 机器人不需要连接显示器、鼠标或键盘。
- 通电后不要触碰电路板、镜头、支架和 CSI 排线。

## 怎样拿棋盘

1. 两只手拿硬板的背面或空白边缘。
2. 手指不能遮住任何黑白方格。
3. 棋盘正面朝向机器人前方的两个镜头。
4. 起始时让棋盘长边保持水平（横着拿）；只有听到“像方向盘一样旋转”时才转动它。
5. 双肘尽量靠近身体，减少手抖。
6. 移动用 1～2 秒；到位后完全停住 2～3 秒。
7. 在听到“收到”前，不要自行换姿势。

如果拿板容易抖，可以坐着拿，让硬板底边轻靠稳定物体；但不能把板掰弯。

## 距离怎么理解

距离是“棋盘到两个相机镜头”的距离，不是到机器人外壳或雷达的距离。主要使用三个大致距离：

- 近：约 30 cm；
- 中：约 50 cm；
- 远：约 70 cm。

不需要拿尺实时测量，大致达到即可。通常不要近于 25 cm，也不要远于 90 cm。

任何时候都要让完整棋盘同时进入两个镜头的共同视野。棋盘四周应留一点空间，不能被画面边缘切掉。持板人看不到相机画面没有关系，电脑旁操作者会告诉您“往中间一点”或“退远一点”。

## 方向口令

为避免“左右”理解相反，所有方向都以 **持板人面对机器人时自己的方向** 为准：

- “往左”：向持板人的左手方向平移；
- “往右”：向持板人的右手方向平移；
- “往上/下”：整块板举高/降低；
- “左边靠近”：板的左边更靠近机器人，右边稍远；
- “右边靠近”：板的右边更靠近机器人，左边稍远；
- “上边靠近”：板的上边更靠近机器人；
- “下边靠近”：板的下边更靠近机器人。

如果没听懂口令，先保持不动再询问，不要猜。

## 实际动作顺序

不需要背下面的顺序，电脑旁操作者会逐项发出口令。每个动作都要停稳 2～3 秒，并等到“收到”。

### 第一组：正面和不同距离

棋盘基本正对相机，不要倾斜：

1. 中间，约 50 cm；
2. 中间，靠近到约 30 cm；
3. 中间，退到约 70 cm。

### 第二组：覆盖画面不同位置

回到约 50 cm，棋盘仍基本正对相机：

1. 中间；
2. 左边；
3. 右边；
4. 上方；
5. 下方；
6. 左上；
7. 右上；
8. 左下；
9. 右下。

到边缘时不要追求“越边越好”；只要完整棋盘仍可见即可。

### 第三组：左右倾斜

回到中间、约 50 cm：

1. 左边稍微靠近机器人；
2. 右边稍微靠近机器人；
3. 棋盘整体稍靠左，再重复左右倾斜；
4. 棋盘整体稍靠右，再重复左右倾斜。

倾斜约 15°～25°即可。不要转成接近侧面，完整棋盘必须仍然可见。

### 第四组：上下倾斜

回到中间、约 50 cm：

1. 上边稍微靠近机器人；
2. 下边稍微靠近机器人；
3. 棋盘举高一点，再重复一次；
4. 棋盘降低一点，再重复一次。

### 第五组：像方向盘一样旋转

棋盘仍大致面向相机，只在纸张平面内转动：

1. 左高右低，约 10°～20°；
2. 右高左低，约 10°～20°；
3. 近距离约 30 cm，各重复一次；
4. 远距离约 70 cm，各重复一次。

### 第六组：按口令补缺少的姿势

电脑会检查左右、上下、远近和倾斜是否足够。操作者可能继续说：

- 再靠近或再退远；
- 往左上或右下移动；
- 倾斜再明显一点；
- 倾斜小一点；
- 回到中间；
- 保持不动。

此时只照口令操作。不要快速挥动棋盘来“多拍几张”；同一个姿势停很久也不会代替不同姿势。

## 每个姿势的固定节奏

1. 听清口令。
2. 用 1～2 秒平稳移动到新位置。
3. 到位后立即停住。
4. 保持 2～3 秒，不晃动。
5. 等操作者说“收到”或给出调整口令。
6. 再进入下一个姿势。

## 绝对不要做

- 不要移动或转动机器人。
- 不要碰镜头、双目相机 PCB 或相机支架。
- 不要拉扯、按压或插拔橙色 CSI 排线。
- 不要弯曲、卷起或扭曲棋盘。
- 不要用手遮住黑白方格。
- 不要把棋盘靠得过近，或让它超出相机画面。
- 不要做超过约 35°～40°的剧烈倾斜。
- 不要连续快速挥动棋盘。
- 不要在中途突然开关灯或改变光照。

如果机器人、相机或支架被碰动，立即保持原状并告诉操作者；不要自己把相机“掰回去”。

## 常见口令和处理办法

### “没有识别到棋盘”

1. 回到机器人正前方和相机同高位置。
2. 保持约 50 cm。
3. 棋盘正对两个镜头。
4. 确认整张棋盘无任何遮挡。
5. 保持不动 3 秒。
6. 检查是否有反光或大片阴影。

仍无法识别时，保持不动，由电脑旁操作者检查画面；不要碰相机。

### “只看到一边”或“退远一点”

棋盘没有同时进入两个镜头的共同视野。请向中间移动、稍微退远，并减小倾斜角度，然后停稳。

### “这个姿势已经有了”

说明新姿势与旧姿势太相似。按操作者口令，明显改变位置、距离或倾斜方向，再停稳。

### 棋盘反光

将棋盘轻微倾斜几度，或调整灯光方向。不要用手挡光，以免手影遮住棋盘。

### 手抖明显

双肘靠近身体，坐下持板，或让硬板底边轻靠稳定物体；到位后再让操作者采集。

## 什么时候完成

只有电脑旁操作者明确说“质量检查通过，标定完成”后，才能放下棋盘。出现“已经收够照片”不代表一定完成，电脑还要检查误差和约 60 mm 的双目基线。

完成后：

1. 缓慢把棋盘拿离机器人。
2. 不要再碰相机和支架。
3. 保存这张硬质标定板，后续检查可能还会使用。
4. 日后只要两个镜头的相对位置发生改变，就必须重新标定。

## 给电脑旁操作者的提醒

- 持板人只负责动作；启动、监看、判定和保存都由操作者完成。
- 每收到一对有效样本，再说“收到”；没有收到时给出一个具体调整口令。
- 不要同时说多个方向，一次只说一个动作。
- 结束必须以自动质量门通过为准，不能只看样本数量。
