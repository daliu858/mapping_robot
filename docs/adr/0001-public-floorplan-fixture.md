# 公开合成样例的测试依赖与成图边界

日期：2026-10-21。状态：用户已批准。

原有房间分割实际依赖 SciPy 和 scikit-image，原有绘图使用 Matplotlib。
只安装最初列出的五项依赖无法运行既有分割测试或 v3.2 合成样例；替换
距离变换、骨架或分水岭实现会超出本轮“不改几何算法”的范围。因此保留
原算法、阈值和绘图框架，在 `requirements-test.txt` 补齐上述三项实际依赖。
测试环境不安装模型、GPU、ROS 或 rosbag 依赖；只有依赖对应环境的测试可跳过。
部分既有静态测试还需上游源码，CI 在临时目录调用 `setup_workspace.sh` 组装
固定版本并通过 `JETBOT_TEST_SRC` 指定位置；不将上游源码加入 Git。未组装的
本地环境会明确跳过这些源码契约，四项核心测试不受影响。补丁应用仅增加
忽略上下文空白差异的选项，以兼容上游的混合行尾，补丁内容保持原样。

合成栅格用 `synthetic: true` 标记，只影响通用区域命名，不选择另一套分割
算法。`--no-visibility` 明确跳过轨迹可见性检查。共享标注布局仅调整文字
位置、大小及引线，避开 POI 并保留完整房间名与面积；它不修改任何几何数据。

现有两张住宅成图和 logo 保持原文件不变。验收使用合成数据单独导出 PNG、
SVG 和区域 YAML，核对四类 POI（包括原坐标上的红色 spray 星标）及文字布局。
